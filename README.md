## 💡 Featured Projects

- **[InsightVision](https://github.com/SyedBurhanAhmed/InsightVision-MVP) — On-Device Vision-Language Surveillance**
  Offline FastAPI microservice orchestrating Grounding DINO/SAM3 + BoT-SORT detection-and-tracking with Gemma 4 OCR and prompt-driven natural-language querying, running at ~11.5GB peak VRAM on a single GPU. Undergraduate capstone project, AVR Research Group.

- **MoE Expert Pruning — Gemma-4-26B**
  Domain-specific pruning pipeline that profiled 1.9M token-routing decisions to remove 960 of 3,840 experts, delivering a measured 10.51× inference speedup (10.78→113.35 TPS) and fitting the full model in a 16GB VRAM budget.

- **BookItUp Recommendation Engine — Production AI Recommendation System**
  Integrated a recommendation engine into the production backend of a live booking platform at OptimusFox via optimized FastAPI endpoints, returning results in under 300ms and often under 100ms.

  YOLOv11 face detection + EfficientNetV2-S celebrity classification across 15+ Pakistani celebrities. 🏆 **1st place, Computer Vision Kaggle competition.**

- **[RULEN](https://github.com/SyedBurhanAhmed/RULEN-Real-time-Unified-Lecture-Extraction-Network) — Multilingual Lecture Assistant**

- **[Freak AI](https://github.com/SyedBurhanAhmed/Freak-AI) — Memory-Augmented Conversational Agent**
